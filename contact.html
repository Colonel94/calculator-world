Contact & Report a Problem

Found a calculation that looks wrong, an inaccessible control or a broken link? Use the project’s GitHub issue tracker. Reading reports is public; submitting a report requires a GitHub account.

Make an error report useful

Include the calculator page, non-sensitive example inputs, the result you received and the result you expected. A formula or reliable reference helps reproduce a calculation problem.

Keep personal information private

GitHub issues are public. Use invented example amounts and dates instead of account details, medical records or other identifying information. This site does not offer individual advice or customer support, and a response is not guaranteed.
