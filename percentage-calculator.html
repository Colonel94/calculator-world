Percentage Calculator

Find a percentage of a value and the value after a percentage increase or decrease.

Example values are filled in. Replace them with your own; all fields are required.

Your result

Check the example values, then select Calculate.

How to use this calculator

  1. Enter value, percentage (%).
  2. Select Calculate to see the result. After your first calculation, results update as you edit.
  3. Read the assumptions below to check that this model fits your question.

Formula and method

Part = value × percentage ÷ 100. Increased value = value + part. Decreased value = value − part.

Worked example

15% of 200 is 30. Increasing 200 by 15% gives 230; decreasing it gives 170.

Assumptions and interpretation

Signed inputs are supported. A negative percentage reverses the direction of increase and decrease. For the percentage between two values use Percentage Change.

Common question

How do I enter fifteen percent?

Enter 15, not 0.15. The calculator divides the percentage by 100.
