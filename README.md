# Calculator World

A fast, static, SEO-focused collection of free calculators. Built for GitHub Pages and prepared for eventual advertising integration.

## Publishing
Enable GitHub Pages from the main branch / root. The expected URL is https://colonel94.github.io/calculator-world/

## Before AdSense
Deploy the site, connect Google Search Console, submit sitemap.xml, build organic traffic, then apply for AdSense. Replace reserved ad placeholders only after approval.
